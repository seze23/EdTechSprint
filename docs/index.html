Two agents, one prompt.

A study tool where two AI agents answer the same homework question under different decision profiles, and the student sets the dials.

Every AI study tool hides a tradeoff: answer now, or understand later. This one makes it the interface. A student types a prompt and gets two answers side by side from two agents that read the same drafts and value them differently.

SprintFinal answer first. Short. No hedging. For the problem set due tonight.
CoachWorked steps, a check for understanding, a clarifying question when the drafts disagree. For the exam next month.

The dials

Four parameters that computational neuroscience has shown to be real, measurable, and different from one person to the next.

ParameterWhat the student sees
Temporal discounting (k)Learn it ↔ Answer now
Loss aversion (λ)Just tell me ↔ Flag uncertainty
Inverse temperature (β)Surprise me ↔ Consistent
Information bonus (ρ)Assume ↔ Ask first

How a choice is made

Each draft is scored on a few deterministic features: where the final answer sits, how many steps, whether it checks itself, how much it hedges, how many of the other drafts agree with it. A profile is a linear decision boundary over those features. The chosen draft is the one with the largest margin, and the per-feature contributions are shown on every answer. Accept or reject moves the boundary with a hinge-loss update. Learning rates are fit from the student's own history, not set.

What this answers

What students say they hateWhat the design does
Confident wrong answersAn agreement count across drafts on every answer, instead of a confidence claim.
Free scan, locked steps, surprise chargesOne flat price, cancel in one click, stated in the interface.
Answer machines that call themselves tutorsThe teach-versus-answer tradeoff is labelled on each agent and set by the student.
Fake adaptivityThe profile drift is shown after each judgment, not asserted.
